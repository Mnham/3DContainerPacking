# 3D Container Packing

Проект для размещения 3D-объектов в контейнерах с интерактивной демонстрацией результата.

Это форк библиотеки упаковки контейнеров, в котором алгоритм был существенно доработан и ускорен. Основной фокус проекта - быстро найти вариант размещения объектов по контейнерам и наглядно показать получившуюся раскладку.

Демо: https://mnham.github.io/3DContainerPacking/
